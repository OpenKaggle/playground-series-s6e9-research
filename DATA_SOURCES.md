# Data sources

This archive contains no competition rows, labels, test data, external datasets,
or submissions.

| Need | Canonical source | Requirement |
| --- | --- | --- |
| Official competition inputs | [Playground Series S6E9](https://www.kaggle.com/competitions/playground-series-s6e9) | Sign in, accept the rules, and download to a private local directory. |
| Optional external EV data | Referenced in `reports/public_lgbm_audit_2026-09-09.md` | Use only after checking access, license, provenance, and the competition rules. It is intentionally not bundled here. |

No Kaggle-provided data should be re-uploaded to this repository or re-hosted
as an OpenKaggle mirror.
